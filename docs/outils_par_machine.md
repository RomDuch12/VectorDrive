# Outils : par machine, reconnus, conseillés

## Outils propres à chaque machine

- Gestionnaire d'outils › Plus (ou clic droit) › **Machines…** : sur quelles machines (post-processeurs)
  les outils choisis — ou tous ceux d'un dossier — sont montés. Aucune machine cochée : l'outil sert
  partout.
- Partout où l'on choisit un outil (choix d'un outil, gestionnaire, propositions des formulaires,
  choix automatique d'un nouveau parcours), seuls les outils de la machine du réglage FAO sont proposés ;
  la case **Outils de : …** décochée les montre tous (réglage gardé).
- Panneau FAO : un outil réservé à d'autres machines que celle choisie est signalé en orange.
- Après un import d'outils, une indication rappelle qu'ils servent partout tant qu'on ne les a pas
  réservés (le dossier importé reste choisi pour Machines…).

## Reconnaître un outil

- Silhouette en icône, cotes dans le libellé (« T12 Fraise 2 — Ø2 L4 Z2 »), fiche complète en infobulle et
  à côté de la silhouette : nature, cotes, fournisseur et référence, vitesses, dossier, machines.
- Panneau FAO : chaque outil du document dit s'il est dans Mes outils (et dans quel dossier) ; **Outils ›
  Copier les outils absents dans Mes outils** les y range.

## Choisir le bon outil

Dans le formulaire d'une opération :

- **Vérifier l'outil** : l'outil choisi atteint-il tous les détails des formes fermées à usiner ? Part de
  surface hors d'atteinte, et plus gros diamètre qui passe partout.
- **Outil conseillé** : le plus gros outil adapté à la stratégie (voir
  [outils proposés par opération](outils_par_operation.md)) qui atteint tous les détails, parmi les outils
  du document et ceux de Mes outils de la machine ; il est choisi dans la liste.
